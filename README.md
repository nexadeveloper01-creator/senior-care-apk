# 어르신 방문 통합돌봄 서비스 — 모바일 앱 설치 파일

지자체 어르신 방문 통합돌봄 플랫폼(https://senior-welfare-2026-new.web.app)의 Android 설치 파일(APK) 배포용 저장소입니다.

| 앱 | 파일 | 대상 |
|---|---|---|
| 👵 어르신 안심돌봄 | `senior_elder_app.apk` | 어르신 (서비스 신청·긴급 호출·음성 안내) |
| ✂️ 돌봄 요양사 | `senior_provider_app.apk` | 미용사·요양보호사·간호사 (콜 선점·완료 보고·정산) |

## 설치 방법
1. 안드로이드 휴대폰에서 아래 **Releases**의 APK 파일을 내려받습니다.
2. "알 수 없는 앱 설치 허용" 안내가 나오면 허용합니다.
3. 설치 후 앱을 열고 이메일·비밀번호로 로그인합니다(처음이면 [처음이에요 (가입)]).

## 버전

앱은 웹 플랫폼을 그대로 감싼 형태라 기능 업데이트는 재설치 없이 자동 반영됩니다.
